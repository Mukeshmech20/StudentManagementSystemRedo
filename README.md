# Student Management System

A console-based Student Management System developed using Java.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Duplicate ID validation
- Student detail validation
- File-based data persistence

## Technologies Used

- Java
- OOP
- ArrayList
- Collections
- File Handling
- Input Validation

## Project Structure

- `model` – Student data model
- `repository` – File handling and data abstraction
- `service` – CRUD and business logic
- `util` – Input validation
- `Main.java` – Console user interface
